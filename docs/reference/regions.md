## Konsekwencje produktowe

1. dashboard glowny filtruje region warszawski,
2. sekcja `ostatnio zaciagniete` pokazuje tez rekordy spoza regionu, jesli parser tymczasowo zle przypisal lokalizacje,
3. import RCN jest ograniczony do tego obszaru,
4. rozbudowa na inne regiony bedzie osobnym etapem.
